## Hard list

- `func_0211199c` (296 bytes): a typed VLA-based implementation produced the
  correct instruction sequence and size, but allocated the permutation pointer,
  loop counter and upper random bound to r5/r6/r4 instead of r4/r5/r6.
  Tried separate pointer/storage declarations, signed/unsigned element types,
  separate loop variables, explicit bound calculations, and declaration order.
  None matched; omitted the definition and retained the external declaration.
- `func_021115d4` (968 bytes): reconstructed resource lookup, 0xfffe/0xfffd text
  handling, table fallback, and dynamic 33-halfword buffer in typed C. Initial
  output was 960 bytes; correcting halfword loop counters and moving the fixed
  packed buffer outside the VLA scope produced 976 bytes. Stack was 108 rather
  than 104 bytes, with an extra spilled VLA restoration pointer and different
  resource/text register allocation. Omitted the nonmatching definition.

Both remain supplied by the original delinked object, as this DS repository uses
delink fallback rather than INCLUDE_ASM stubs. A human can create nds_arm9 scratches
with `tools/decompme.py` for these two functions. No scratch was uploaded.
