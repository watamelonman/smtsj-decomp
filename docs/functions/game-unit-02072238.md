- `func_02072238` (308 B): resets the two panel flags at +0x3e1/+0x3e2, zeros a variable-length
  id array sized by the work area's entry count at +0x357, fills it from the slot ids selected by
  the area keys, clears the 60-byte buffer at +0x2f8, calls `func_02068cf8`, records its byte at
  +0x352 and updates the used-slot count at +0x158 via the `Unk06a224` helpers.
- `func_020769f8` (340 B): rebuilds the panel id/flag arrays. For each row it pairs the selected
  slot id with the row slot id (`func_02067ef4`), looks the definition up with `func_020a1428`,
  refreshes the shared text handle, and copies either the matched slot byte at +0x38 or the
  definition byte at +3 into `panel.flags`. Finally submits the handle with `func_02061f10` and
  redraws the id list with `func_02067418`.
- `func_02076b50` (572 B): selects a colour band from `v` and submits one text draw call with the
  band-specific offset (`v-28`, `v-19`, `v-10`, `v-1`, `v+8`, `v+17`); the last band also calls
  `func_02057df8` first.
- `func_02076d8c` (576 B): draws the area-record list, one row per area entry. Rows with an
  invalid key get a full-width row (offset `y`), valid rows are drawn in two columns (rows are
  22 pixels apart); then it draws the panel header/footer and redraws the description via
  `func_02067c88`.
- `func_02076fcc` (588 B): same list drawing as `func_02076d8c`, but marks the selected row
  (`s16` at +0x228) with its own text id and draws the remaining rows around it.
